# The Pawn Desk

Static site for the Pawn Desk pricing tools.

- `index.html` — desk (counter) view
- `phone.html` — phone view
- `sw.js` — offline service worker
- `manifest.webmanifest` / `manifest-phone.webmanifest` — install manifests
- icon PNGs — app icons

Served with GitHub Pages from the `main` branch, root folder:

- https://jacef8.github.io/pawn-desk/
- https://jacef8.github.io/pawn-desk/phone.html
